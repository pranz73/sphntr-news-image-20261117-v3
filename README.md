# The Midnight Wire

A cream, black and red tabloid poster summing up the supplied world news for Tuesday, 17 November 2026. The artwork and typography are built in one self-contained HTML page with inline SVG illustrations.

## Run it

Render the poster with Chromium:

```sh
node render.mjs
```

Copy the rendered PNG to the output directory (defaults to `/output`):

```sh
node --experimental-strip-types main.ts
```
